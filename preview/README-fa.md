# راهنمای Tanish Arts Preview

ابزار خصوصی برای اینکه تامبنیل را قبل از پرداخت به مشتری نشان بدهید، بدون اینکه بتواند فایل قابل‌استفاده‌ای بردارد.
بعد از پرداخت، **همان لینک** دکمهٔ دانلود فایل اصلی را نشان می‌دهد.

---

## ۱. آپلود روی هاست (cPanel)

1. روی کامپیوتر، پوشهٔ `preview` را **زیپ کنید** (روی پوشه راست‌کلیک ← Compress / Send to ← Compressed folder).
2. وارد cPanel شوید و **File Manager** را باز کنید.
3. وارد پوشهٔ `public_html` شوید.
4. بالای صفحه روی **Upload** بزنید و فایل `preview.zip` را آپلود کنید.
5. به File Manager برگردید، روی `preview.zip` راست‌کلیک کنید و **Extract** را بزنید.
6. حالا باید پوشهٔ `public_html/preview` را داشته باشید (داخلش `admin.php`، `p.php`، `storage` و … است). فایل zip را پاک کنید.
7. در File Manager از منوی **Settings** (بالا سمت راست) گزینهٔ **Show Hidden Files** را روشن کنید و مطمئن شوید فایل‌های `.htaccess` و `.user.ini` هم آپلود شده‌اند. این فایل‌ها برای امنیت لازم‌اند.

> مهم: فایل‌های مخفی (`.htaccess`) گاهی موقع زیپ‌کردن در مک جا می‌مانند. حتماً مرحلهٔ ۷ را چک کنید.

### دسترسی پوشه‌ها
معمولاً لازم نیست کاری بکنید. اگر در صفحهٔ راه‌اندازی خطای «قابل نوشتن نیست» دیدید: روی پوشهٔ `preview/storage` و زیرپوشه‌هایش راست‌کلیک ← **Change Permissions** ← عدد **755**.

### نسخهٔ PHP
در cPanel ← **MultiPHP Manager** نسخهٔ دامنه را **PHP 8.0 یا بالاتر** بگذارید. افزونهٔ **GD** باید فعال باشد. در اکثر هاست‌ها به‌صورت پیش‌فرض فعال است. اگر نبود: cPanel ← **Select PHP Version** ← تیک `gd`.

### حد آپلود (برای فایل‌های تا ۲۵ مگابایت)
فایل `.user.ini` داخل پوشه حد آپلود را بالا می‌برد. اگر پنل هنوز پیام «حد آپلود این سرور …» نشان داد:
cPanel ← **MultiPHP INI Editor** ← دامنه را انتخاب کنید و این مقادیر را بگذارید:

| تنظیم | مقدار |
|---|---|
| `upload_max_filesize` | `26M` |
| `post_max_size` | `120M` |
| `memory_limit` | `512M` |
| `max_execution_time` | `180` |

## ۲. راه‌اندازی (فقط یک بار)

1. در مرورگر باز کنید: `https://tanisharts.com/preview/setup.php`
2. لیست بررسی‌ها را نگاه کنید. همه باید تیک سبز ✓ داشته باشند.
3. یک **رمز عبور قوی** (حداقل ۸ کاراکتر) وارد کنید و دکمهٔ «ذخیرهٔ رمز و ورود» را بزنید.
4. تمام! از این به بعد `setup.php` دیگر کار نمی‌کند. برای امنیت بیشتر می‌توانید فایل `setup.php` را از File Manager پاک کنید.

> این کار را **بلافاصله بعد از آپلود** انجام دهید تا کسی قبل از شما رمز نگذارد.

**رمز را فراموش کردید؟** در File Manager فایل `preview/storage/config.php` را پاک کنید و دوباره `setup.php` را باز کنید. اگر `setup.php` را پاک کرده بودید، دوباره آپلودش کنید. پروژه‌ها از بین نمی‌روند.

---

## ۳. ساخت پروژه برای مشتری

1. وارد پنل شوید: `https://tanisharts.com/preview/admin.php`
2. روی **«+ پروژهٔ جدید»** بزنید.
3. فرم را پر کنید:
   - **نام مشتری:** در صفحهٔ مشتری می‌آید: «Thumbnail preview for …».
   - **نام روی واترمارک (انگلیسی):** اسمی که روی تصویر چاپ می‌شود تا اگر عکس لو رفت، معلوم باشد مال کدام مشتری است. حروف فارسی در واترمارک درست چاپ نمی‌شوند، پس انگلیسی بنویسید.
   - **تاریخ انقضا (اختیاری):** بعد از این روز، مشتری فقط پیام «This preview has expired» می‌بیند.
   - **عنوان ویدیو، نام کانال، آواتار، بازدید، زمان انتشار، مدت ویدیو:** همان چیزهایی که در کارت یوتیوب دیده می‌شود. به انگلیسی بنویسید، مثلاً `1.4M views`، `3 days ago`، `24:18`.
   - **تامبنیل‌ها:** ۱ تا ۴ نسخه (A، B، C، D). فرمت JPG، PNG یا WebP تا ۲۵ مگابایت.
   - **رقبا (اختیاری):** لینک چند ویدیوی یوتیوب هم‌موضوع، هر خط یکی. اگر بخواهید عنوان و نام کانال آن ویدیو هم نمایش داده شود، این‌طور بنویسید:
     ```
     https://youtu.be/xxxxxxxxxxx | Video title | Channel name
     ```
4. روی **«ساخت پروژه»** بزنید و چند ثانیه صبر کنید.

برای عوض‌کردن نسخه‌ها یا اطلاعات، داخل پروژه دکمهٔ **«ویرایش»** را بزنید.

---

## ۴. ارسال لینک برای مشتری

1. در صفحهٔ پروژه روی **«کپی لینک برای مشتری»** بزنید.
2. لینک را در دیسکورد/تلگرام/ایمیل برای مشتری بفرستید. شکل لینک این است:
   `https://tanisharts.com/preview/p/xxxxxxxxxxxxxxxxxxxxxxxx`
3. مشتری تامبنیل را در این حالت‌ها می‌بیند: فید دسکتاپ، فید موبایل، ستون «Up next» و نتایج جست‌وجو. حالت تاریک و روشن یوتیوب هم دارد. اگر چند نسخه گذاشته باشید، می‌تواند نسخه‌ها را کنار هم مقایسه کند.
4. مشتری نسخهٔ موردعلاقه و نظرش را ثبت می‌کند. در پنل، داخل همان پروژه، بخش **«نظر مشتری»** را ببینید. وقتی مشتری نسخه‌ای انتخاب کند، وضعیت خودکار «تایید شده» می‌شود.

> اگر لینک کوتاه `/p/…` روی هاست شما کار نکرد، لینک جایگزین (`p.php?id=…`) زیر کادر لینک نوشته شده و همیشه کار می‌کند.

### مشتری چه چیزی می‌تواند بردارد؟
فقط یک تصویر **۶۴۰ پیکسلی، کم‌کیفیت و واترمارک‌دار** با اسم خودش. فایل اصلی در پوشه‌ای ذخیره شده که از هیچ آدرسی در اینترنت قابل‌دسترسی نیست. اسکرین‌شات را نمی‌شود جلویش را گرفت، ولی همین کیفیت پایین و واترمارکِ اسم‌دار محافظت اصلی است.

---

## ۵. بعد از پرداخت

1. در پنل وارد پروژه شوید.
2. دکمهٔ سبز **«علامت‌گذاری به‌عنوان پرداخت‌شده»** را بزنید.
3. به مشتری بگویید **همان لینک قبلی** را دوباره باز کند (یا صفحه را رفرش کند). حالا دکمهٔ **«Download full resolution»** را می‌بیند و فایل اصلی را بدون واترمارک و با کیفیت کامل دانلود می‌کند.

- اشتباه زدید؟ دکمهٔ **«لغو پرداخت»** دانلود را دوباره قفل می‌کند.
- پروژهٔ پرداخت‌شده منقضی نمی‌شود، تا مشتری همیشه به فایلش دسترسی داشته باشد.

### حذف پروژه
پایین صفحهٔ پروژه دکمهٔ **«حذف پروژه»** را بزنید و تایید کنید. پروژه، همهٔ فایل‌ها و نظرها برای همیشه پاک می‌شوند و لینک مشتری دیگر کار نمی‌کند.

---

## نکته‌ها

- **لوگو:** اگر فایلی با نام `logo.png` در پوشهٔ `preview/assets/img/` بگذارید، به‌جای لوگوی متنی در صفحهٔ مشتری نمایش داده می‌شود.
- **منطقهٔ زمانی:** پیش‌فرض تهران است. برای تغییر، در `storage/config.php` مقدار `timezone` را عوض کنید.
- **پشتیبان‌گیری:** همهٔ اطلاعات داخل پوشهٔ `preview/storage` است. برای بکاپ، همین پوشه را دانلود کنید.
- **تامبنیل رقبا** را مرورگر مشتری مستقیم از یوتیوب می‌گیرد، نه سرور شما. اگر لینکی اشتباه باشد، کارت خاکستری نمایش داده می‌شود.
- اگر سایت پشت **Cloudflare** است، محدودیت تلاش ورود بر اساس IP کلودفلر حساب می‌شود. کار می‌کند، ولی دقیق نیست.

## تست روی کامپیوتر خودتان (اختیاری، برای برنامه‌نویس)

اگر PHP 8 روی سیستم نصب است، در پوشه‌ای که `preview` داخلش است بزنید:

```
php -S localhost:8080 -t preview
```

بعد `http://localhost:8080/setup.php` را باز کنید. لینک‌های `/p/<id>` و `p.php?id=<id>` هر دو کار می‌کنند.
سرور داخلی PHP فایل `.user.ini` را نمی‌خواند و حد آپلودش ۲ مگابایت است. برای تست فایل‌های بزرگ‌تر این را بزنید:

```
php -d upload_max_filesize=26M -d post_max_size=120M -d memory_limit=512M -S localhost:8080 -t preview
```
